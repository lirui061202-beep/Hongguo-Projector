# 红果投影版 · Hongguo Projector

**只是为了让大家可以躺着开电视刷红果。**

拿起遥控器，上下刷不同短剧；看到喜欢的，按一下确定进入这部剧，继续上下切集、连续看。这个小改版从家里投影仪的使用需求出发，免费分享源码，方便大家自己使用、研究和改进。

本项目基于 [HGTV v1.2.4.1](https://github.com/pan8664716/HGTV/tree/v1.2.4.1) 修改，面向安卓电视与投影仪。原项目已经具备电视界面、遥控操作、搜索、选集和播放器；本分支主要调整的是**打开就刷、刷剧与追剧切换的操作流程，以及投影默认设置**。与红果官方没有关联。

## 与原版有什么不同

以下对比对象为 HGTV v1.2.4.1，并非红果官方手机客户端。

| 场景 | 原版 HGTV | 本投影分支 |
| --- | --- | --- |
| 打开应用 | 以首页剧架、榜单和分类浏览为主 | 首页新数据加载后自动进入短剧预览，也保留首页“开始刷剧”入口 |
| 想随便刷一刷 | 从目录或搜索结果选择剧目 | 预览时按 ↑ / ↓ 切换上一部、下一部短剧；已有队列刷完后可继续加载 |
| 决定追这部剧 | 通过原有详情、播放和选集操作观看 | 按确定、点击画面，或看完预览后进入当前剧；↑ / ↓ 改为上一集、下一集，播完自动续集 |
| 从追剧返回 | 原有页面返回流程 | 先返回刷剧预览，再返回目录或搜索，方便继续挑剧 |
| 快速找选集和搜索 | 原有电视选集、搜索及播放设置 | 刷剧时可用菜单键，键盘可用 M / F10，直接打开选集、搜索、继续刷剧和画面选项 |
| 首页内容 | 原有多榜单和分类入口 | 增加面向刷剧的搜索内容剧架；单个分区失败时仍展示其他可用分区 |
| 分集加载 | 原版详情路径 | 改用客户端分集接口，修复本次遇到的网站详情 HTTP 500；预览获取分集失败时尝试下一部，避免卡在失效条目 |
| 应用身份 | 红果TV，`com.hgtv.star` | 红果投影版，`com.hgtv.star.projector`，可与原版并存 |

**保留的功能：**搜索剧名、选集、连续播放、播放进度和画面模式等沿用原项目。本分支没有重新发明这些功能，也不提供全部剧目永久可播放的保证。

### 与此前的投影测试包相比

- **取消默认拉伸铺满，恢复“完整画面”。**保留视频原比例，竖屏短剧两侧留黑边，人物不被横向拉宽，也不裁掉画面。三种画面模式原版已有，本次是恢复默认值。
- 覆盖安装后首次启动会自动恢复一次完整画面；之后记住用户自行选择的画面模式。
- 保留上下刷剧、确认进入本剧、上下切集、自动续播、选集与搜索。
- 修复打开即报详情 HTTP 500，并在预览时跳过无法加载的剧目。在线内容与视频服务器仍可能偶发失败。

## 下载与安装

从本仓库 [Releases](../../releases) 下载 **`Hongguo-Projector-ready.apk`**，通过电视或投影仪的文件管理器安装。需要允许文件管理器“安装未知应用”。ADB 可用时也可以：

```sh
adb install -r Hongguo-Projector-ready.apk
```

应用显示名称为“红果投影版”。相同签名的本分支安装包可以覆盖安装；原版 HGTV 与本分支包名不同。自行编译使用自己的签名，不能覆盖本仓库安装包。

当前应用版本保持 **1.2.4.1 / 60**；GitHub 发布标签用来标识投影分支快照，没有修改应用版本号。

**更新请使用本仓库的安装包。**继承代码中的应用内更新仍指向上游 HGTV，不能作为本投影分支的更新渠道，安装器会检查包名与签名。

## 遥控器与键盘

| 操作 | 刷剧预览 | 已进入当前剧 |
| --- | --- | --- |
| ↑ / ↓ | 上一部 / 下一部短剧 | 上一集 / 下一集 |
| 确定 / Enter | 进入当前剧 | 暂停 / 继续 |
| 点击画面 | 进入当前剧 | 暂停 / 继续 |
| 本集播完 | 进入当前剧并续播下一集 | 自动续播下一集 |
| 返回 / Esc | 返回目录或搜索 | 回到刷剧预览 |
| 菜单 / M / F10 | 打开播放菜单 | 打开播放菜单 |

菜单中仍用方向键选择选项。画面不合适时，选择 **画面模式 → 完整画面**。

## 设备与验证范围

- Android 4.4（API 19）及以上；需要网络。实际解码和流畅程度取决于设备及片源。
- 本次需求来自极米 Z7X、GMUI 6.11 的使用反馈，未完成所有电视型号的兼容验证。
- 当前原比例版本已编译 debug，并验证 APK 签名；投影仪上的最终画面和按键体验需实际安装确认。
- 前一内容修复版本在电脑 JVM 上通过 46 项本机检查，并取到真实分集、完整下载并解码一集约 90 秒的视频，验证了搜索与下一集地址；这些检查不等同于投影仪播放验证。本次画面默认值更新没有重跑内容检查。
- 内容与视频服务可能变化，曾出现 HTTP 500、视频 403 或超时。当前修复针对已观察到的问题，无法保证所有剧目、所有时段均可播放。

本仓库不包含影视视频文件，也不提供影视内容的版权许可。

## 从源码构建

需要 JDK 17、Android SDK Platform 36、Gradle Wrapper 8.14.3。设置 `ANDROID_HOME`，或在 `android/local.properties` 中设置 SDK 路径。构建文件当前使用 Media3 1.3.1。

源码不含签名私钥。首次构建，先在仓库根创建自己的调试密钥（以下 `android` 为标准调试密码，并非项目私有凭据）：

```sh
mkdir -p local-signing
keytool -genkeypair -keystore local-signing/projector-debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
./android/gradlew -p android :app:assembleDebug
```

Windows PowerShell 可用 `New-Item -ItemType Directory -Path local-signing -Force` 创建目录，构建命令为：

```powershell
.\android\gradlew.bat -p android :app:assembleDebug
```

安装包输出在 `android/app/build/outputs/apk/debug/app-debug.apk`。

`android/app` 为电视界面与播放器，`android/core` 为内容请求、分集、刷剧队列及媒体读取；原项目文档和历史变更保留在 `docs/`。原版说明保留在 [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md)，其中下载地址和功能描述属于上游历史记录。
